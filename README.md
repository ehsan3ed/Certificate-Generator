# سازنده گواهینامه (Certificate Studio)

اپلیکیشن وب ایستا برای طراحی و صدور گواهینامه چندزبانه (فارسی / انگلیسی / عربی) با پشتیبانی RTL/LTR، قالب‌های آماده، لوگو، عکس هنرجو و مدرس، QR اعتبار و خروجی PNG/PDF.

نام‌های **هنرجو** و **مدرس** در رابط و متن پیش‌فرض به‌صورت متغیر هستند؛ مقدار واقعی را هنگام صدور وارد می‌کنید.

## اجرا در ویندوز (مستقل)

### روش ۱ — دوبارکلیک

1. فایل `start-windows.bat` را اجرا کنید.
2. مرورگر روی `http://127.0.0.1:8765` باز می‌شود.

نیاز: [Python 3](https://www.python.org/downloads/) روی PATH، یا در صورت نبود پایتون از روش ۲ استفاده کنید.

### روش ۲ — بدون نصب (PowerShell)

```powershell
.\start-windows.ps1
```

اگر پایتون نباشد، اسکریپت از `npx --yes serve` استفاده می‌کند (نیاز به Node.js).

### روش ۳ — باز کردن مستقیم

فقط برای تست سریع: `index.html` را در مرورگر باز کنید. برای Service Worker و برخی قابلیت‌ها سرور محلی توصیه می‌شود.

## اتصال به سایت پندنیک (اختیاری)

اگر از داخل پنل پندنیک باز شود، توکن و آدرس API از طریق `postMessage` / query ارسال می‌شود و می‌تواند:

- اطلاعات هنرجو را در دیتابیس ذخیره کند
- QR اعتبار (`/c/...`) بسازد
- تصویر نهایی گواهی را آپلود کند

بدون اتصال هم به‌صورت آفلاین طراحی و خروجی فایل کار می‌کند.

## ساختار

```
index.html          رابط اصلی
css/styles.css      استایل
js/app.js           منطق ویرایشگر
js/themes.js        قالب‌ها و متن‌های چندزبانه
assets/             لوگو و قاب قالب‌ها
vendor/             html2canvas, jsPDF, qrcode
tools/              اسکریپت‌های ساخت قالب (پایتون)
start-windows.bat   اجرای محلی ویندوز
```

## قوانین QR

| موقعیت | منبع | کاربر عادی |
|--------|------|------------|
| QR راست | پروفایل / کارت ویزیت مدرس | فقط جابه‌جایی و اندازه |
| QR چپ | لینک اعتبار پس از صدور | فقط جابه‌جایی و اندازه |

## انتشار در GitHub

این پوشه برای ریپوی مستقل آماده است:

```bash
cd D:\App-Certificate
git init
git add .
git commit -m "Initial commit: Certificate Studio"
gh repo create pandenik-certificate-studio --private --source=. --push
```

فایل‌های شخصی نمونه و زیپ‌ها در `.gitignore` هستند.
